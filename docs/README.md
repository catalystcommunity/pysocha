# Pysocha documentation

Pysocha is a static site generator. It reads Markdown content and Jinja
templates. It writes a directory of files. No code runs on the server.

For installation and a first site, read the [quickstart](../README.md).

## Contents

- [Configuration](configuration.md) — every configuration key and its default.
- [Content](content.md) — pages, blog posts, front matter, and content regions.
- [Markdown](markdown.md) — syntax highlighting and themes.
- [Feeds](feeds.md) — Atom and RSS output.
- [Search](search.md) — search configuration and the two supplied providers.
- [Search providers](search-providers.md) — how to write your own provider.
- [Build behavior](building.md) — the commands, staged output, and the preview
  server.
